# VAB Builder (KSP)

Update channel for the VAB Builder Android app: a Kerbal Space Program vehicle builder
with staging, Δv, R&D tech tree and building levels.

- `app/VAB-Builder.apk` — the Android app (install once).
- `app/index.html` — the builder page; the installed app downloads newer versions automatically.
- `app/version.json` — the current page and app versions the app checks on launch.
