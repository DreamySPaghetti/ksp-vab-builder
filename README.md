# Ship Optimizer (KSP)

Update channel for the Ship Optimizer Android app (the installed app is still labelled "VAB Builder").
Pick the Kerbal Space Program parts you have and a goal; the app works out the best rocket or spaceplane
from them, entirely on the phone: stages, boosters, Δv per phase, thrust-to-weight, stability, career
tech nodes and building limits, every planet and moon, and aircraft tasks around Kerbin.

- `app/VAB-Builder.apk` — the Android app (install once).
- `app/index.html` — the optimizer page; the installed app downloads newer versions automatically.
- `app/version.json` — the current page version (`web`) the app checks; currently update 27.
