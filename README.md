# Mission Companion (KSP 1.12, career)

Update channel for the Mission Companion Android app (the installed app is still labelled "VAB Builder").
Set your researched tech and building levels once, pick a mission, and the app designs the craft from your
unlocked parts, then walks you through the flight burn by burn: launch profile, transfer angle or window date,
capture, landing, ascent, return and re-entry. Everything runs on the phone.

- `app/VAB-Builder.apk` — the Android app (install once).
- `app/index.html` — the app page; the installed app downloads newer versions automatically.
- `app/version.json` — the current page version (`web`) the app checks.
